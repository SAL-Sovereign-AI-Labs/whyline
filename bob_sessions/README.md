# bob_sessions

Task session summary screenshots, one PNG per Bob task, as the hackathon guide requires:
Bob IDE, Tasks list, open the task, click the task header, screenshot the consumption summary, save as PNG.

File name: `whyline_<dev>_task<NN>_<slug>.png` (for example `whyline_a_task03_why_skill.png`).
Next to each PNG, the raw task export if Bob offers it (`..._export.json`).
Costs go in costs.md after every task.
